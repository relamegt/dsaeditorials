# Addition & Subtraction of Decimals

Addition and subtraction of decimals are fundamental arithmetic operations frequently tested in quantitative aptitude examinations. These operations are used in problems involving money, measurements, distance, weight, time, fuel consumption, statistics, and data interpretation. Mastering decimal arithmetic improves calculation speed and accuracy in competitive exams.

---

# Core Concept

Decimal addition and subtraction are performed in the same way as whole numbers, with one important rule:

**Always align the decimal points before performing the calculation.**

If the numbers have different numbers of decimal places, add trailing zeros where necessary. Trailing zeros do not change the value of a decimal.

### Example

Add

**12.5 + 8.75**

Write both numbers with equal decimal places.

```Code
12.50
+ 8.75
------
 21.25
```

**Answer:** **21.25**

---

# Key Rules

## Rule 1: Align the Decimal Points

Always write the decimal points directly below one another.

### Example

```Code
6.25
+14.80
------
 21.05
```

---

## Rule 2: Add Trailing Zeros

If necessary, add zeros to make the decimal places equal.

### Example

Instead of

```Code
3.5
2.75
```

Write

```Code
3.50
2.75
```

---

## Rule 3: Perform Normal Addition or Subtraction

Once the decimal points are aligned, add or subtract exactly as you would with whole numbers.

### Example

```Code
15.80
- 6.25
------
  9.55
```

---

# Step-by-Step Method

## Addition

1. Write the numbers vertically.
2. Align the decimal points.
3. Add trailing zeros if necessary.
4. Add the digits column by column.
5. Place the decimal point directly below the other decimal points.

---

## Subtraction

1. Write the numbers vertically.
2. Align the decimal points.
3. Add trailing zeros if required.
4. Subtract digit by digit.
5. Place the decimal point directly below the other decimal points.

Find

# Competitive Exam Tricks

### Trick 1

Always align the decimal points before performing calculations.

---

### Trick 2

Add trailing zeros whenever decimal places differ.

Example

```Code
6.5 = 6.50
```

---

### Trick 3

Ignore the decimal point temporarily, perform the addition or subtraction, and then place the decimal point in the correct position.

---

### Trick 4

Estimate the answer mentally to detect calculation mistakes.

Example

```Code
19.8 + 10.3 ≈ 30
```

If your calculated answer is far from 30, recheck your work.

---

# Common Mistakes

- Not aligning decimal points correctly.
- Forgetting to add trailing zeros.
- Placing the decimal point in the wrong position.
- Borrowing incorrectly during subtraction.
- Performing calculations from left to right instead of right to left.

---

# Exam Tips

- Always align decimal points vertically.
- Write missing decimal places using trailing zeros.
- Estimate the answer before solving.
- Check the decimal point after completing the calculation.
- Practice both numerical and word problems regularly.

---

# Summary

Addition and subtraction of decimals follow the same rules as whole-number arithmetic, provided the decimal points are aligned correctly. Adding trailing zeros when necessary ensures accurate calculations. Regular practice with decimal arithmetic improves speed and reduces errors in competitive examinations.
