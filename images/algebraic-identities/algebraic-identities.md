# Algebraic Identities

In arithmetic and algebraic analysis, **Algebraic Identities** are equality equations that hold true for any values substituted for their variables. They serve as fundamental shortcuts, allowing complex multiplications, expansions, and fractions to be simplified rapidly without performing tedious long calculations.

## Square Identities

Square identities form the foundation of quadratic expansions and factorization.

### Fundamental Formulas

- **Sum Square**: $(a + b)^2 = a^2 + 2ab + b^2$
- **Difference Square**: $(a - b)^2 = a^2 - 2ab + b^2$
- **Difference of Squares**: $a^2 - b^2 = (a - b)(a + b)$

### Practical Calculations

- **Area Difference of Square Surfaces**: Find the difference in area between a larger square of side $75$ cm and a smaller square of side $25$ cm.
- Set up the calculation: $75^2 - 25^2$.
- Apply the Difference of Squares identity: $(75 - 25)(75 + 25)$.
- Simplify: $50 \times 100 = 5000$ $\text{cm}^2$.
- **Surface Area Expansion**: Find the value of $(a + b)^2$ when $a = 43$ and $b = 7$.
- Substitute the values: $(43 + 7)^2 = 50^2 = 2500$.
- **Shortcut Mental Multiplication**: Calculate $104 \times 96$ without long multiplication.
- Express the factors around base 100: $(100 + 4)(100 - 4)$.
- Apply the Difference of Squares identity: $100^2 - 4^2$.
- Simplify: $10000 - 16 = 9984$.
- **Expression Simplification**: Find the value of $87^2 - 2(87)(37) + 37^2$.
- This expression fits the identity $a^2 - 2ab + b^2$ where $a = 87$ and $b = 37$.
- Simplify: $(a - b)^2 = (87 - 37)^2 = 50^2 = 2500$.

## Cubic Identities

Cubic identities represent the expansion and factoring of third-power terms.

### Fundamental Formulas

- **Sum of Cubes**: $a^3 + b^3 = (a + b)(a^2 - ab + b^2)$
- **Difference of Cubes**: $a^3 - b^3 = (a - b)(a^2 + ab + b^2)$

### Practical Calculations

- **Simplifying Sum of Cubes Fractions**: Evaluate the expression $\frac{1.05^3 + 0.95^3}{1.05^2 - 1.05 \times 0.95 + 0.95^2}$.
- The expression matches the form $\frac{a^3 + b^3}{a^2 - ab + b^2}$.
- Factoring the numerator gives $\frac{(a + b)(a^2 - ab + b^2)}{a^2 - ab + b^2} = a + b$.
- Substitute: $1.05 + 0.95 = 2.0$.
- **Simplifying Difference of Cubes Fractions**: Evaluate the expression $\frac{64^3 - 34^3}{64^2 + 64 \times 34 + 34^2}$.
- The expression matches the form $\frac{a^3 - b^3}{a^2 + ab + b^2}$.
- Factoring the numerator gives $\frac{(a - b)(a^2 + ab + b^2)}{a^2 + ab + b^2} = a - b$.
- Substitute: $64 - 34 = 30$.

## Reciprocal Identities

Reciprocal identities are a subset of quadratic equations where one variable is the reciprocal of the other ($b = \frac{1}{x}$). This simplifies the middle term $2ab$ to just $2$.

### Fundamental Formulas

- $(x + \frac{1}{x})^2 = x^2 + \frac{1}{x^2} + 2 \implies x^2 + \frac{1}{x^2} = (x + \frac{1}{x})^2 - 2$
- $(x - \frac{1}{x})^2 = x^2 + \frac{1}{x^2} - 2 \implies x^2 + \frac{1}{x^2} = (x - \frac{1}{x})^2 + 2$

### Practical Calculations

- **Single Power Expansion**: If $x + \frac{1}{x} = 7$, find the value of $x^2 + \frac{1}{x^2}$.
- Square both sides: $(x + \frac{1}{x})^2 = 7^2 \implies x^2 + \frac{1}{x^2} + 2 = 49$.
- Subtract 2: $x^2 + \frac{1}{x^2} = 49 - 2 = 47$.
- **Double Power Expansion**: If $x - \frac{1}{x} = 4$, find the value of $x^4 + \frac{1}{x^4}$.
- Square both sides of the initial difference equation: $(x - \frac{1}{x})^2 = 4^2 \implies x^2 + \frac{1}{x^2} - 2 = 16$.
- Find the intermediate quadratic sum: $x^2 + \frac{1}{x^2} = 16 + 2 = 18$.
- Square this intermediate sum: $(x^2 + \frac{1}{x^2})^2 = 18^2 \implies x^4 + \frac{1}{x^4} + 2 = 324$.
- Subtract 2: $x^4 + \frac{1}{x^4} = 324 - 2 = 322$.

## Three-Variable and Conditional Identities

Three-variable identities relate the sum, product, and squares of three variables.

### Fundamental Formulas

- $a^3 + b^3 + c^3 - 3abc = (a + b + c)(a^2 + b^2 + c^2 - ab - bc - ca)$
- **Alternate Form**: $a^3 + b^3 + c^3 - 3abc = (a + b + c)((a + b + c)^2 - 3(ab + bc + ca))$

### The Conditional Rule

If $a + b + c = 0$, then the right side of the identity becomes $0$, resulting in:
$$a^3 + b^3 + c^3 = 3abc$$

### Practical Calculations

- **Sum of Cubes under Zero-Sum Condition**: Find the value of $a^3 + b^3 + c^3$ if $a = 25$, $b = 25$, and $c = -50$.
- Check the conditional sum: $a + b + c = 25 + 25 + (-50) = 0$.
- Apply the conditional rule: $a^3 + b^3 + c^3 = 3abc$.
- Calculate: $3 \times 25 \times 25 \times (-50) = 3 \times 625 \times (-50) = -93,750$.
- **Evaluating Three-Variable Systems**: Find the value of $x^3 + y^3 + z^3$ given $x + y + z = 12$, $xy + yz + zx = 47$, and $xyz = 60$.
- Use the alternate three-variable form:

    $$x^3 + y^3 + z^3 - 3xyz = (x + y + z)((x + y + z)^2 - 3(xy + yz + zx))$$

- Substitute the values:

    $$x^3 + y^3 + z^3 - 3(60) = 12 \times (12^2 - 3(47))$$
    $$x^3 + y^3 + z^3 - 180 = 12 \times (144 - 141) = 12 \times 3 = 36$$

- Add 180 to isolate the sum of cubes:

    $$x^3 + y^3 + z^3 = 36 + 180 = 216$$

## Application Scenarios: Quantitative Reasoning

Identities are widely used in geometry and financial forecasting to simplify calculations:

- **Mohit** is a builder designing adjacent square storage plots. The larger plot side is $75$ meters and the smaller is $25$ meters. To find the difference in land area, he uses the Difference of Squares identity:

  $$75^2 - 25^2 = (75 - 25)(75 + 25) = 50 \times 100 = 5000 \text{ m}^2$$
  This allows him to calculate the area difference mentally without squaring large numbers.

- **Akash** is auditing financial interest adjustments. He simplifies a cubic compound ratio representing budget expansion:

  $$\frac{1.05^3 + 0.95^3}{1.05^2 - 1.05 \times 0.95 + 0.95^2}$$
  By applying the Sum of Cubes factorization, he collapses the complex fraction to $1.05 + 0.95 = 2.0$, verifying the budget expansion factor instantly.

### ⚠️ Important: The Conditional Identity Sign Trap

When applying the conditional rule ($a^3 + b^3 + c^3 = 3abc$), pay careful attention to the signs of the variables. For example, if $a = 25, b = 25,$ and $c = -50$, their sum is $0$, meaning $a^3 + b^3 + c^3 = 3(25)(25)(-50) = -93,750$. Forgetting to carry the negative sign from $c$ into the product $3abc$ is a common error that yields positive $93,750$, which is incorrect. Always double-check variable signs when substituting into identity products.

# Summary

Algebraic identities simplify quantitative calculations by rewriting complex powers and products into manageable components. Square identities help solve area differences and shortcut multiplications, while cubic factorizations collapse fractional ratios. Reciprocal equations isolate quadratic and quartic sums, and three-variable conditional rules simplify cube additions under zero-sum states. These rules form the mathematical shortcut system for solving variable equations, proving polynomial equivalences, and answering test patterns in quantitative aptitude.
