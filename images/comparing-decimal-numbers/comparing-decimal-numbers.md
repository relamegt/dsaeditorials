# Comparing Decimal Numbers

Comparing decimal numbers is a fundamental arithmetic skill that is frequently tested in quantitative aptitude examinations. It is used in measurements, money, time, data interpretation, percentages, statistics, and everyday calculations. Understanding how to compare decimals accurately helps avoid common mistakes and improves calculation speed in competitive exams.

---

# Core Concept

Decimal numbers are compared by examining their digits from **left to right**.

- First compare the whole number part.
- If the whole number parts are equal, compare the digits after the decimal point one place at a time.
- If necessary, add trailing zeros to make both decimals have the same number of decimal places. Adding trailing zeros does **not** change the value of a decimal.

### Example

Compare

\[
3.45 \quad \text{and} \quad 3.450
\]

Since trailing zeros do not change the value,

\[
3.45 = 3.450
\]

---

# Key Rules

### Rule 1: Compare the Whole Number Part

The decimal with the larger whole number part is greater.

**Example**

\[
8.25 &gt; 7.99
\]

because

\[
8&gt;7
\]

---

### Rule 2: Compare Decimal Places from Left to Right

If the whole numbers are equal, compare the tenths, then hundredths, then thousandths, and so on.

**Example**

Compare

\[
5.46 \quad \text{and} \quad 5.43
\]

Tenths are equal.

Compare hundredths.

\[
6&gt;3
\]

Therefore,

\[
5.46&gt;5.43
\]

---

### Rule 3: Add Trailing Zeros if Required

Decimals with different numbers of decimal places can be compared by adding zeros to the shorter decimal.

**Example**

Compare

\[
2.5 \quad \text{and} \quad 2.500
\]

Both numbers are equal.

\[
2.5=2.500
\]

---

# Step-by-Step Method

Follow these steps to compare decimal numbers.

1. Compare the whole number part.
2. If they are equal, compare the tenths digit.
3. If still equal, compare the hundredths digit.
4. Continue comparing one digit at a time.
5. Add trailing zeros whenever necessary to make comparison easier.

# Standard Question Types

## Type 1: Identify the Largest Decimal

### Example

Find the largest number.

\[
3.42,\;3.402,\;3.4,\;3.405
\]

### Solution

Write all numbers with equal decimal places.

\[
3.420
\]

\[
3.402
\]

\[
3.400
\]

\[
3.405
\]

Comparing digit by digit,

\[
3.420&gt;3.405&gt;3.402&gt;3.400
\]

**Answer:** **3.42**

---

## Type 2: Identify the Smallest Decimal

### Example

Find the smallest number.

\[
1.45,\;1.5,\;1.405,\;1.42
\]

### Solution

Write with equal decimal places.

\[
1.450
\]

\[
1.500
\]

\[
1.405
\]

\[
1.420
\]

Therefore,

\[
1.405&lt;1.420&lt;1.450&lt;1.500
\]

**Answer:** **1.405**

---

## Type 3: Arrange Decimals in Ascending Order

### Example

Arrange in ascending order.

\[
0.8,\;0.82,\;0.805,\;0.81
\]

### Solution

Equalize decimal places.

\[
0.800,\;0.820,\;0.805,\;0.810
\]

Ascending order:

\[
0.800&lt;0.805&lt;0.810&lt;0.820
\]

**Answer:**

\[
0.8,\;0.805,\;0.81,\;0.82
\]

---

## Type 4: Arrange Decimals in Descending Order

### Example

Arrange in descending order.

\[
4.15,\;4.105,\;4.2,\;4.125
\]

### Solution

Equalize decimal places.

\[
4.150,\;4.105,\;4.200,\;4.125
\]

Descending order:

\[
4.200&gt;4.150&gt;4.125&gt;4.105
\]

**Answer:**

\[
4.2,\;4.15,\;4.125,\;4.105
\]

# Solved Examples

## Example 1

A grocer weighs four bags of apples.

- Bag A = **1.45 kg**
- Bag B = **1.50 kg**
- Bag C = **1.405 kg**
- Bag D = **1.42 kg**

Which bag is the lightest?

### Solution

Equalize decimal places.

\[
1.450,\;1.500,\;1.405,\;1.420
\]

Comparison:

\[
1.405&lt;1.420&lt;1.450&lt;1.500
\]

**Answer:** **Bag C**

---

## Example 2

Four athletes complete a race in the following times.

- Runner 1 = **12.35 s**
- Runner 2 = **12.05 s**
- Runner 3 = **12.50 s**
- Runner 4 = **12.30 s**

Who wins the race?

### Solution

The athlete with the lowest time wins.

\[
12.05&lt;12.30&lt;12.35&lt;12.50
\]

**Answer:** **Runner 2**

---

## Example 3

A stock market report shows daily growth.

- Share A = **3.04%**
- Share B = **3.40%**
- Share C = **3.004%**
- Share D = **3.402%**

Which share recorded the highest growth?

### Solution

Equalize decimal places.

\[
3.040,\;3.400,\;3.004,\;3.402
\]

Comparison:

\[
3.402&gt;3.400&gt;3.040&gt;3.004
\]

**Answer:** **Share D**

---

## Example 4

Rainfall recorded over four days is:

- Monday = **0.82 mm**
- Tuesday = **0.802 mm**
- Wednesday = **0.89 mm**
- Thursday = **0.815 mm**

Which day recorded the highest rainfall?

### Solution

Equalize decimal places.

\[
0.820,\;0.802,\;0.890,\;0.815
\]

Comparison:

\[
0.890&gt;0.820&gt;0.815&gt;0.802
\]

**Answer:** **Wednesday**

## Example 5

Four chemical compounds have the following purity levels.

- P = **98.45%**
- Q = **98.50%**
- R = **98.405%**
- S = **98.52%**

Arrange them in descending order.

### Solution

\[
98.450,\;98.500,\;98.405,\;98.520
\]

Descending order:

\[
98.520&gt;98.500&gt;98.450&gt;98.405
\]

**Answer:**

S &gt; Q &gt; P &gt; R

Four delivery vans have the following fuel efficiencies.

# Competitive Exam Tricks

### Trick 1

Always compare the whole number part first.

---

### Trick 2

If the whole numbers are equal, compare digits after the decimal one place at a time.

---

### Trick 3

Add trailing zeros whenever the decimals have different numbers of decimal places.

Example

\[
5.4=5.400
\]

---

### Trick 4

Never compare decimals only by counting the number of digits after the decimal point.

For example,

\[
0.5=0.500
\]

Both represent the same value.

---

# Common Mistakes

- Comparing the number of decimal digits instead of the actual values.
- Ignoring the whole number part.
- Forgetting that trailing zeros do not change the value.
- Comparing digits from right to left instead of left to right.
- Misplacing decimal points while rewriting numbers.

---

# Exam Tips

- Equalize the number of decimal places before comparing.
- Compare one digit at a time from left to right.
- Memorize that trailing zeros do not affect the value of a decimal.
- Practice arranging decimals in ascending and descending order to improve speed.

---

# Summary

Comparing decimal numbers involves comparing the whole number parts first and then comparing the decimal digits from left to right. Adding trailing zeros can simplify comparisons without changing the value of the numbers. Mastering these techniques helps solve quantitative aptitude questions involving measurements, percentages, money, and data interpretation quickly and accurately.
