# Comparing Decimal Numbers

Comparing decimal numbers is a fundamental arithmetic skill that helps determine which decimal is greater, smaller, or equal. It is widely used in quantitative aptitude, measurements, money, percentages, statistics, and data interpretation. Mastering decimal comparison improves both speed and accuracy in competitive examinations.

---

# Core Concept

To compare decimal numbers:

1. Compare the **whole number** part.
2. If the whole numbers are equal, compare the **tenths** digit.
3. If the tenths are also equal, compare the **hundredths** digit.
4. Continue comparing each decimal place from left to right until a difference is found.
5. If the numbers have different decimal lengths, add trailing zeros to the shorter decimal. This does **not** change its value.

### Example

Compare **3.45** and **3.450**.

Adding a trailing zero gives:

**3.450** and **3.450**

Therefore,

**3.45 = 3.450**

---

# Key Rules

## Rule 1: Compare the Whole Number Part

If the whole number parts are different, the decimal with the larger whole number is greater.

### Example

Compare **8.25** and **7.99**.

Since **8 &gt; 7**, therefore **8.25 &gt; 7.99**.

---

## Rule 2: Compare Decimal Places

If the whole number parts are equal, compare the decimal digits from left to right.

### Example

Compare **5.46** and **5.43**.

- Whole numbers are equal.
- Tenths digits are equal.
- Compare the hundredths digits.

Since **6 &gt; 3**, therefore **5.46 &gt; 5.43**.

---

## Rule 3: Add Trailing Zeros

Trailing zeros do not change the value of a decimal.

### Example

Compare **2.5** and **2.500**.

Write both numbers with equal decimal places.

**2.500** and **2.500**

Therefore,

**2.5 = 2.500**

---

# Step-by-Step Method

Follow these steps whenever you compare decimal numbers.

1. Compare the whole number part.
2. If they are equal, compare the tenths digit.
3. Continue comparing hundredths, thousandths, and subsequent decimal places.
4. Add trailing zeros whenever necessary.
5. Stop as soon as the first unequal digit is found.

# Standard Question Types

## Type 1: Find the Largest Decimal

### Example

Find the largest number.

- 3.42
- 3.402
- 3.4
- 3.405

### Solution

Write all numbers with equal decimal places.

- 3.420
- 3.402
- 3.400
- 3.405

Comparison:

**3.420 &gt; 3.405 &gt; 3.402 &gt; 3.400**

**Answer:** **3.42**

---

## Type 2: Find the Smallest Decimal

### Example

Find the smallest number.

- 1.45
- 1.5
- 1.405
- 1.42

### Solution

Equalize the decimal places.

- 1.450
- 1.500
- 1.405
- 1.420

Ascending order:

**1.405 &lt; 1.420 &lt; 1.450 &lt; 1.500**

**Answer:** **1.405**

---

## Type 3: Arrange in Ascending Order

### Example

Arrange the following in ascending order.

- 0.8
- 0.82
- 0.805
- 0.81

### Solution

Equalize the decimal places.

- 0.800
- 0.820
- 0.805
- 0.810

Ascending order:

**0.800 &lt; 0.805 &lt; 0.810 &lt; 0.820**

Therefore,

**0.8, 0.805, 0.81, 0.82**

---

## Type 4: Arrange in Descending Order

### Example

Arrange the following in descending order.

- 4.15
- 4.105
- 4.2
- 4.125

### Solution

Equalize the decimal places.

- 4.150
- 4.105
- 4.200
- 4.125

Descending order:

**4.200 &gt; 4.150 &gt; 4.125 &gt; 4.105**

Therefore,

**4.2, 4.15, 4.125, 4.105**

# Solved Examples

## Example 1

A grocer weighs four bags of apples.

| Bag | Weight |
| --- | --- |
| A | 1.45 kg |
| B | 1.50 kg |
| C | 1.405 kg |
| D | 1.42 kg |

Which bag is the lightest?

### Solution

Equalize the decimal places.

- 1.450
- 1.500
- 1.405
- 1.420

Comparison:

**1.405 &lt; 1.420 &lt; 1.450 &lt; 1.500**

**Answer:** **Bag C**

---

## Example 2

Four athletes complete a race in the following times.

| Runner | Time |
| --- | --- |
| 1 | 12.35 s |
| 2 | 12.05 s |
| 3 | 12.50 s |
| 4 | 12.30 s |

Who wins the race?

### Solution

The athlete with the lowest time wins.

**12.05 &lt; 12.30 &lt; 12.35 &lt; 12.50**

**Answer:** **Runner 2**

---

## Example 3

A stock market report shows the following daily gains.

| Share | Growth |
| --- | --- |
| A | 3.04% |
| B | 3.40% |
| C | 3.004% |
| D | 3.402% |

Which share recorded the highest growth?

### Solution

Equalize the decimal places.

- 3.040
- 3.400
- 3.004
- 3.402

Comparison:

**3.402 &gt; 3.400 &gt; 3.040 &gt; 3.004**

**Answer:** **Share D**

---

## Example 4

Rainfall recorded over four days:

| Day | Rainfall |
| --- | --- |
| Monday | 0.82 mm |
| Tuesday | 0.802 mm |
| Wednesday | 0.89 mm |
| Thursday | 0.815 mm |

Which day recorded the highest rainfall?

### Solution

Equalize the decimal places.

- 0.820
- 0.802
- 0.890
- 0.815

Comparison:

**0.890 &gt; 0.820 &gt; 0.815 &gt; 0.802**

**Answer:** **Wednesday**

# Competitive Exam Tricks

- Compare the whole number part first.
- Compare decimal digits from left to right.
- Add trailing zeros whenever necessary.
- Stop as soon as the first unequal digit is found.
- Remember that trailing zeros do not change the value.

---

# Common Mistakes

- Ignoring the whole number part.
- Comparing only the number of decimal digits.
- Forgetting to add trailing zeros.
- Comparing digits from right to left.
- Assuming a longer decimal is always greater.

---

# Exam Tips

- Rewrite decimals with the same number of decimal places before comparing.
- Compare digits one place at a time.
- Practice arranging decimals in ascending and descending order.
- Remember:
- **0.5 = 0.50 = 0.500**

All represent the same value.

---

# Summary

Comparing decimal numbers involves comparing the whole number part first, followed by the decimal digits from left to right. Adding trailing zeros makes comparisons easier without changing the value. Mastering this technique helps solve quantitative aptitude questions quickly and accurately.
