# Converting Decimals to Fractions

Converting decimals to fractions is a fundamental arithmetic skill that is frequently tested in quantitative aptitude examinations. It is widely used in percentages, ratio and proportion, probability, measurements, and everyday calculations. Understanding the conversion process enables you to solve problems accurately and efficiently.

---

# Core Concept

A **decimal** represents a number based on the place value system, while a **fraction** represents a part of a whole. Every terminating decimal can be expressed as a fraction by writing the decimal over the appropriate power of 10 and simplifying it to its lowest terms.

For example,

\[
0.75=\frac{75}{100}=\frac34
\]

---

# Key Rules

### Rule 1: Write the Decimal as a Fraction

Remove the decimal point and write the resulting number as the numerator.

Use:

- 10 for one decimal place
- 100 for two decimal places
- 1000 for three decimal places
- and so on.

**Example**

\[
0.45=\frac{45}{100}
\]

---

### Rule 2: Simplify the Fraction

Reduce the fraction by dividing both the numerator and denominator by their Highest Common Factor (HCF).

**Example**

\[
\frac{45}{100}
=
\frac9{20}
\]

---

### Rule 3: Convert Mixed Decimals

For decimals greater than 1, first convert the decimal part into a fraction, then combine it with the whole number.

**Example**

\[
3.125
=
3+\frac{125}{1000}
=
3+\frac18
=
3\frac18
=
\frac{25}{8}
\]

---

# Types of Decimal Numbers

## 1. Terminating Decimals

A terminating decimal has a finite number of digits after the decimal point.

Examples

\[
0.5=\frac12
\]

\[
0.625=\frac58
\]

\[
0.875=\frac78
\]

---

## 2. Recurring (Repeating) Decimals

A recurring decimal has one or more digits that repeat indefinitely.

Examples

\[
0.\overline3=\frac13
\]

\[
0.\overline6=\frac23
\]

\[
0.\overline{27}=\frac{27}{99}=\frac3{11}
\]

Recurring decimals require special methods for conversion and are usually covered separately.

---

# Step-by-Step Method

Follow these steps to convert a decimal into a fraction.

1. Count the number of digits after the decimal point.
2. Remove the decimal point to obtain the numerator.
3. Write the appropriate power of 10 as the denominator.
4. Simplify the fraction using the HCF.
5. If the decimal is greater than 1, write the answer as a mixed number or an improper fraction.

# Standard Question Types

## Type 1: Simple Decimal Conversion

Convert the decimal directly into a fraction.

### Example

Convert

\[
0.45
\]

### Solution

\[
0.45=\frac{45}{100}
\]

Simplify

\[
\frac{45}{100}
=
\frac9{20}
\]

**Answer:** **9/20**

---

## Type 2: Decimal Greater Than One

### Example

Convert

\[
12.75
\]

### Solution

\[
12.75
=
12+\frac{75}{100}
=
12+\frac34
=
12\frac34
\]

Improper fraction

\[
12\frac34
=
\frac{51}{4}
\]

**Answer:** **12¾** or **51/4**

---

## Type 3: Three Decimal Places

### Example

Convert

\[
0.625
\]

### Solution

\[
0.625
=
\frac{625}{1000}
\]

Divide numerator and denominator by 125.

\[
=
\frac58
\]

**Answer:** **5/8**

# Competitive Exam Tricks

### Trick 1

Count the decimal places to determine the denominator.

| Decimal Places | Denominator |
| --- | --- |
| 1 | 10 |
| 2 | 100 |
| 3 | 1000 |
| 4 | 10000 |

---

### Trick 2

Always simplify the fraction using the Highest Common Factor (HCF).

For example,

\[
\frac{80}{100}
=
\frac45
\]

---

### Trick 3

Memorize common decimal-to-fraction conversions such as:

- 0.25 = 1/4
- 0.5 = 1/2
- 0.75 = 3/4
- 0.125 = 1/8
- 0.625 = 5/8
- 0.875 = 7/8

This saves valuable time during examinations.

---

# Common Mistakes

- Forgetting to simplify the fraction.
- Using the wrong denominator based on the number of decimal places.
- Miscounting the decimal places.
- Writing an incorrect mixed number for decimals greater than 1.
- Confusing terminating decimals with recurring decimals.

---

# Exam Tips

- Count the decimal places carefully before writing the denominator.
- Simplify the fraction to its lowest terms.
- Memorize common decimal-to-fraction equivalents.
- Convert mixed decimals into both mixed numbers and improper fractions when required.
- Practice recurring decimal conversions separately, as they use a different method.

---

# Summary

Converting decimals to fractions involves writing the decimal as a fraction with a denominator that is a power of 10 and then simplifying it using the Highest Common Factor (HCF). Mastering this process, along with common decimal-to-fraction conversions, helps solve quantitative aptitude problems quickly and accurately in competitive examinations.
