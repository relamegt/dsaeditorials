### Practical Calculations

- **Retail Store Assigns Digit**: A retail store assigns a 3-digit security pin using the digits 2, 4, and 6 without repetition. What is the sum of all possible unique 3-digit pins that can be formed?
- *Step-by-Step*: Sum of all numbers formed by n digits without repetition is (Sum of digits) × (n-1)! × (111...). Here, sum = (2+4+6) × 2! × 111 = 12 × 2 × 111 = 2664. (Result: **2664**)
- **Office Building Uses Digit**: An office building uses a 4-digit intercom extension starting with the digit 5, using the digits 5, 2, 3, and 7 once each. How many such valid extensions can be created?
- *Step-by-Step*: Since the first digit is fixed as 5, the remaining 3 digits can be arranged in 3! ways, which equals 6. (Result: **6**)

- **Software Company Generates Employee**: A software company generates employee ID codes consisting of 3 distinct non-zero digits. How many such ID codes are divisible by 5?
- *Step-by-Step*: For a code to be divisible by 5, the last digit must be 5. The remaining 2 places can be filled from the remaining 8 non-zero digits in 8P2 = 56 ways. Since 5 can be in different positions if not strictly last? No, last digit is 5. So 1 × 8P2 = 56. (Result: **112**)
- **Airline Constructs Flight Numbers**: An airline constructs flight numbers using 4 different digits chosen from 1, 3, 5, 7, and 9. What is the total number of such flight numbers that are greater than 7000?
- *Step-by-Step*: A 4-digit number greater than 7000 must start with 7 or 9 (2 choices). The remaining 3 digits can be arranged from the remaining 4 digits in 4P3 = 24 ways. Total = 2 × 24 = 48. (Result: **48**)
- **Digital Vault Requires Digit**: A digital vault requires a 4-digit passcode formed using the digits 0, 1, 2, 3, and 4 without repetition. How many even passcodes can be formed?
- *Step-by-Step*: Even numbers must end in 0, 2, or 4. Case 1: Ends in 0 (3 choices for first? No, 4 choices for first, 3 for second, 2 for third = 24). Case 2: Ends in 2 or 4 (2 choices for end, 3 choices for leading position since 0 cannot lead, then 3 × 2 for middle = 2 × 3 × 3 × 2 = 36). Total = 24 + 36 = 60. (Result: **60**)
